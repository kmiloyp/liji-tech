# Textos de la portada, versión 2 (más cercanos)

**Cómo se escribe ahora:**
- Frases cortas, con verbo.
- Se habla de cosas concretas: la caja, el rollo, la bodega, la prensa.
- Una sola idea por sección.
- El usuario se dirige al lector (you / usted).
- Ninguna frase agrega datos que el cliente no haya dado: nada de plazos, mínimos ni cumplimiento normativo.
- Las palabras clave para SEO se quedan en el `<title>`, la descripción y el H1. El tono cambia, la búsqueda no.
